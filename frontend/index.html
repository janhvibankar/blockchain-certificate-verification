How It Works

Simple 3-step process to issue and verify certificates

1

Institute Issues Certificate

Admin connects MetaMask, fills certificate details, uploads certificate file (SHA-256 hash is generated automatically), and submits to blockchain.

2

Data Stored on Blockchain

The smart contract stores certificate data permanently on the blockchain. The transaction is immutable and verifiable by anyone.

3

Anyone Can Verify

Students, employers, or anyone can enter a Certificate ID to instantly retrieve and verify its authenticity directly from the blockchain.

About This Project

Blockchain-Based Certificate Verification System — Final Year Engineering Project

🎯
Project Objective

This DApp demonstrates how blockchain technology can solve the problem of fake academic certificates. Instead of relying on a central database, certificate records are stored on the Ethereum blockchain, making them immutable and publicly verifiable by anyone, anywhere.

🛠️
Technology Stack
⚙️ Solidity 0.8.19
🔨 Hardhat
🌐 ethers.js v6
🦊 MetaMask
📄 HTML5 / CSS3
⚡ Vanilla JavaScript
🔐 SHA-256 (Web Crypto API)
⛓️ Ethereum (Local Hardhat)
🔐
Security Features
  • Only contract owner can issue/revoke certificates
  • Duplicate Certificate IDs are rejected
  • SHA-256 hash detects file tampering
  • All transactions require MetaMask signature
  • No private keys stored in frontend code
  • Revoked certificates are permanently flagged
